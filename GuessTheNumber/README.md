# Guess the Number

A simple Java console game where the player attempts to guess a randomly chosen number within a certain range.

## Description

- The program generates a random number within a specified range.
- The player is prompted to guess the number, and is given feedback on whether the guess is too high or too low.
- The game continues until the correct number is guessed, and the number of attempts is displayed.
- The code demonstrates use of random number generation, basic control flow, and user input handling in Java.
