# Online Reservation System

A basic simulation of an online reservation system coded in Java.

## Description

- This project provides a simple command-line interface for users to manage reservations.
- Functionality includes: creating reservations, viewing reservation details, and canceling reservations.
- The code demonstrates object-oriented programming principles, user interaction, and basic data handling.
